# Usage

Pick a mode from the toolbar, then interact with the splat in the viewport:

- <i class="bi bi-binoculars"></i> **View** — orbit, pan, and zoom the camera.
- <i class="bi bi-brush"></i> **Select** — draw 2D box/polygon selections over the splat.
- <i class="bi bi-magic"></i> **SAM** — click points to segment with SAM2.
